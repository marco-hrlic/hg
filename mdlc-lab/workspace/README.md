# Your lab workspace

Open Claude Code **in this folder** (`cd workspace && claude`). Everything you build lives here.

1. `lab setup` (once): exports the data into `data/`.
2. `lab steps`: the list of steps. `lab step 1.0` to start.
3. For each step: read the card, write your prediction in `notes.md`, give Claude the prompt
   (fill in the decisions), then `lab check <step>`.
4. Stuck or behind? `lab catchup <step>` writes reference outputs so you can carry on.

`data/` and `outputs/` are generated and not committed.
