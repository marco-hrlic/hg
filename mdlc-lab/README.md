# MDLC Lab: Building a Sentiment Classifier

A hands-on model development lifecycle (MDLC) lab for developers who know Python but haven't done ML.
Two 2-hour labs, CPU only. See [PLAN.md](PLAN.md) for the full curriculum.

| Lab | Notebook | Status |
|---|---|---|
| 1. Train a classifier (prepared data, hands-on, light theory) | `notebooks/lab1_train_a_classifier.ipynb` | ready for dry run |
| 2. Open the box (raw data, data engineering, theory, retrain) | `notebooks/lab2_data_and_theory.ipynb` | draft: data block done, theory + retrain to build |

## Setup (before lab 1)

```bash
cd mdlc-lab
pip install -e ".[dev]"     # or: pip install -r requirements.txt
make data                   # downloads ~200 MB once, builds all datasets in ~30 s
jupyter lab notebooks/
```

Works on Python 3.10+ locally or in Colab. No GPU and no API keys needed.

## Layout

```
mdlc/                 helper package: data building, cleaning, dedup, metrics, baselines, slices
notebooks/src/*.py    single source for each lab's notebook
notebooks/*.ipynb     student version (TODO cells raise NotImplementedError)
solutions/*.ipynb     completed version
instructor/           facilitation notes per lab
tests/                pytest suite (`make test`)
data/                 generated by `make data`, not committed
```

Edit `notebooks/src/*.py`, never the `.ipynb` files directly, then run `make notebooks`.
A test fails if the committed notebooks are out of date.

## The data

[Yelp Review Full](https://s3.amazonaws.com/fast-ai-nlp/yelp_review_full_csv.tgz)
(Zhang, Zhao & LeCun, 2015): reviews with 1–5 stars. Labels are mapped 1–2 → negative,
3 → neutral, 4–5 → positive. `make data` builds:

- `prepared/`: lab 1's ready-made train/val/test splits (the reference cleaning pipeline applied to the raw file)
- `raw/reviews_raw.csv`: 20,700 training reviews with **planted problems** for lab 2
  (invalid labels, placeholders, HTML, exact/conflicting/near duplicates, flipped labels,
  a leaky column, file sorted by label, class imbalance)
- `raw/answer_key.csv`: what was planted where (instructor only; `mdlc.data.score_findings` reads it)
- `golden/candidates.csv`: 400 slice-tagged reviews from the official *test* split for golden-set curation
- `golden/exercise_30.csv`: the labelling-agreement exercise
- `heldout/heldout.csv`: 5,000 clean test reviews, locked until the end of lab 2
