# MDLC Lab: Building a Sentiment Classifier with Claude Code

Two 2-hour labs for developers who know Python but haven't done ML. Participants build a
sentiment classifier step by step **with Claude Code**: the agent writes the code, while participants
make the decisions, predict results, and verify the work with an independent harness.

The goal isn't to be able to build this alone afterwards. It's to see every major component,
learn the vocabulary and the ML way of working, so participants can direct agents and research
any part of it themselves.

| Lab | Steps | |
|---|---|---|
| 1. Train a classifier | 1.0–1.7 | prepared data → baselines → features → network and training loop → experiments → evaluation → break it |
| 2. Open the box | 2.1–2.8 | raw data audit → cleaning and splits → labels and the golden set → the maths → loss design → label noise → synthetic data → retrain and compare |

## For participants

```bash
cd mdlc-lab
pip install -e .          # installs the `lab` command
cd workspace
lab setup                 # downloads ~200 MB once, exports the data
claude                    # open Claude Code here
lab step 1.0              # and start
```

Each step card: **why it matters** → **predict first** (in `notes.md`) → **prompt** for Claude Code
with `[DECISION]`s you fill in → **verify** with `lab check` → **go deeper** for later.

## Layout

```
steps/lab1, steps/lab2   step cards (`lab step 1.4` prints one)
workspace/               where participants work: CLAUDE.md for the agent, settings, notes.md
mdlc/                    the harness (`lab` command) and the toolbox it uses
reference/               reference solution for every step (`lab catchup` runs it)
golden_labels/           labelling guideline, draft and final golden labels, review workflow
synthetic/               pre-generated synthetic reviews and the prompt used
notebooks/, solutions/   the same course as two worked notebooks, for self-study
instructor/              facilitation notes
tests/                   `make test`
data/                    generated by `make data` / `lab setup`, never committed
```

## The data
[Yelp Review Full](https://s3.amazonaws.com/fast-ai-nlp/yelp_review_full_csv.tgz)
(Zhang, Zhao & LeCun, 2015). Labels: 1–2 ★ negative, 3 ★ neutral, 4–5 ★ positive.

- **Development data** (from Yelp's train file): lab 1 gets a prepared train/dev split. Lab 2
  starts from the raw export it came from, with planted problems and an answer key.
- **Evaluation data** (from Yelp's separate test file, deduplicated against development data):
  the **golden set** (~380 hard-case-heavy reviews, labels checked against a guideline) and the
  **held-out set** (5,000 reviews, production label mix). Participants get texts only; the harness
  keeps the labels, scores submissions and rations held-out looks.

The source data isn't redistributed: `lab setup` downloads it and rebuilds everything from a fixed
seed, so every participant gets identical files.
